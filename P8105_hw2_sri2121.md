The combined Trash Wheel dataset has 1269 observations and 15 variables,
drawn from Mr. Trash Wheel (740 hauls), Professor Trash Wheel (137
hauls), and Gwynnda (392 hauls). Key variables include `trash_wheel`

``` r
baseline_df_clean = baseline_df |> 
  filter(!is.na(age_at_onset)) |> 
  filter(age_at_onset > current_age)
```

Discussion:

The first row is a description of the columns and the second row is the
actual column name so I skipped the first row while importing. Missing
values have been recorded as “.”, “NA” or a blank space so that has been
accounted for while importing. The dataframe consists of 6 columns,
namely: id, current_age, sex, education, apoe4, age_at_onset.
“current_age” is the age at the study baseline. “education” is years of
education. “sex” is coded as 1 for male and 0 for female. “apoe4” is
coded as 1 for apoe4 carrier and 0 for apoe4 non-carrier. Sex and APOE4
carrier status are stored as numerical data types so I’ve changed them
to factors.

The number of participants recruited is 483.

The number of participants that develop MCI is 93.

The average baseline age is 65.8 years.
